# 최정원 자기소개서

**저는 문제가 있으면 원인과 결과를 파악하는 사람입니다.**

2025년 3월 대전에서 다니던 회사가 경영 악화로 어려워지면서 일을 그만두게 되었습니다. 갑자기 앞으로 무엇을 해야 할지 고민해야 하는 상황이 되었고, 단순히 다른 직장을 찾는 것보다 앞으로 계속할 수 있는 분야가 무엇인지 생각하게 되었습니다. 그 과정에서 새로운 진로로 정보보안을 선택했습니다.

처음 정보보안을 시작했을 때는 익숙하지 않은 내용과 해결되지 않는 문제가 많았습니다. 하지만 문제가 생겼을 때 결과만 빨리 얻기보다는 왜 문제가 발생했는지 하나씩 확인하는 방법을 익혀 갔습니다. 교육 과정에서도 빠르게 접근하기보다 먼저 분석하고 자료를 찾아본 뒤 다시 확인하는 행동을 반복했습니다.

저의 강점은 세 가지입니다.

첫째, 감정이 앞서는 상황에서도 확인 순서를 다시 세우는 **자기조절력**입니다.

둘째, 다른 사람의 의견을 듣고 함께 원인을 좁혀 가는 **대인관계력**입니다.

셋째, 결과가 바로 나오지 않아도 다시 시도하고 맡은 일을 끝까지 이어 가는 **자기동기력**입니다.

2026년 8월 27일에는 잘되지 않는 문제를 붙잡고 있으면서 스스로에게 “너무 열받지 말고 차근차근 하나씩 확인하면서 하자”고 기록했습니다. 이후에도 로그와 설정, 실행 결과를 다시 보면서 원인을 좁히는 방식을 반복했습니다.

교육과 프로젝트에서는 혼자 해결하는 데만 집중하지 않았습니다. 다른 사람의 의견을 듣고 함께 화면을 보며 문제를 확인했습니다. 동료들로부터 활기찬 분위기를 만들고 조 활동과 프로젝트를 주도하려는 모습이 인상적이라는 평가도 받았습니다.

지금은 개발 경험과 정보보안 공부, 인프라 운영 학습을 연결하면서 시스템과 로그를 직접 확인하고 문제의 원인을 찾아가는 역량을 쌓고 있습니다.

**문제를 마주했을 때 묵묵히 원인을 추적하고 분석하는 과정을 넘어, 체계적인 인프라 운영과 견고한 정보보안으로 조직의 신뢰를 지키는 보안 전문가가 되고 싶습니다.**
