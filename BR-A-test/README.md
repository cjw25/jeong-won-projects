# BR-A · 최정원 자기소개 사이트

## 결과물

- 공개 사이트: https://br-a-site.vercel.app
- 공개 연락수단: cnjzzan@naver.com

## 프로젝트 목적

고난에서 다시 일어나 지금의 문제해결 방식으로 이어진 자기소개와,
출석·리추얼·과제 기록의 숫자, 대표작, 지원용 문서를 한 사이트에 정리했다.

## 실행 방법

1. 프로젝트 폴더에서 `python .\tools\update_site.py`를 실행한다.
2. `python .\tools\check_determinism.py`를 실행해 마지막에 `PASS`가 나오는지 확인한다.
3. `python -m http.server 8000` 실행 후 `http://localhost:8000`을 연다.

## 입력 파일

- `data/attendance.json` — 내 출석 기록
- `data/ritual.json` — 내 리추얼 기록
- `data/submissions.json` — 내 제출 현황

## 생성 결과

- `data/generated.json`

새 기록을 입력 파일에 반영한 뒤 `update_site.py`를 실행하면
숫자 카드와 능력별 근거 후보를 다시 생성한다.

## 같은 입력 검증

실행:

`python .\tools\check_determinism.py`

통과 조건:

- run1과 run2의 SHA-256 값이 동일
- 마지막 출력이 `PASS`

최종 확인 결과:

`3d7c7e21e22af4854f61691341e26c0a82430788795d477d1530a449ba02bdbc`

## 짧은 확인 방법

1. https://br-a-site.vercel.app 을 연다.
2. `이야기`에서 자기소개와 세 능력, `숫자`에서 87.1%·28일·11개, `대표작`에서 T10과 T13 자리를 확인한다.
3. `이력서` 영역과 ZIP의 `docs/`, `tools/`, `data/` 폴더를 확인한다.

통과 조건:

- 사이트가 로그인 없이 열린다.
- 이야기·숫자·대표작이 모두 표시된다.
- 이력서·자기소개서·경력기술서 파일이 존재한다.
- 갱신 장치의 동일 입력 검사가 PASS한다.

실패 시 확인:

- 숫자가 없으면 `data/generated.json` 확인
- 갱신 실패 시 `data/*.json` 형식 확인
- 사이트 파일 누락 시 Vercel 배포 로그와 GitHub 파일 확인

## AI와 내 판단

AI에게 맡긴 일: T09·T11과 리추얼 기록을 바탕으로 자기소개 구조, 세 능력의 장면 연결, 사이트 초안과 갱신 장치 구조화를 맡겼다.

내가 직접 판단한 일: 2025년 3월 퇴사를 실제 고난으로 사용하고, 정보보안으로 다시 방향을 정한 과정과 자기조절력·대인관계력·자기동기력에 사용할 실제 장면을 선택했으며 공개할 이메일과 최종 사이트 구성을 결정했다.

AI 제안을 따르지 않은 일: 실제 경험과 다른 시간선이나 직무 표현은 사용하지 않았고, 사실과 다른 부분은 T09와 실제 기록을 기준으로 수정했다.
