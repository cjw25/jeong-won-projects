# T05 고정 검사 계획

## 개선 대상

과제 3 「짤·카드 스튜디오」

## 개선 기능

현재 편집 초안 자동저장 및 복구

사용자가 편집 값을 변경하면 현재 상태를 자동 저장한다.

페이지를 새로고침하거나 다시 열었을 때
마지막 편집 상태를 복구한다.

'새 작업'을 실행한 경우에는 기존 자동저장 초안을 제거하고
앱의 초기 상태로 돌아간다.

기존 템플릿 CRUD, JSON 가져오기/내보내기,
이미지 편집, PNG 다운로드 기능은 유지한다.

---

# 고정 검사 수

정확히 10개

AI A 작업 시작 이후 아래 검사는
삭제, 완화, 입력 변경, 기대값 변경을 하지 않는다.

---

## T05-01 — 문구 복구

입력:

1. 문구를 `대화가 끊겨도 이어진다`로 변경한다.
2. 페이지를 새로고침한다.

기대값:

- 문구 입력란에 `대화가 끊겨도 이어진다`가 표시된다.
- 미리보기에도 같은 문구가 표시된다.

---

## T05-02 — 글자 크기 복구

입력:

1. 글자 크기를 `180px`로 변경한다.
2. 페이지를 새로고침한다.

기대값:

- 글자 크기 표시가 `180px`이다.
- 새로고침 전후 값이 같다.

---

## T05-03 — 문구 폭 복구

입력:

1. 문구 영역 폭을 `20%`로 변경한다.
2. 페이지를 새로고침한다.

기대값:

- 문구 영역 폭 표시가 `20%`이다.
- 새로고침 전후 값이 같다.

---

## T05-04 — 텍스트 위치 복구

입력:

1. 텍스트 X 위치를 `0%`로 변경한다.
2. 텍스트 Y 위치를 `100%`로 변경한다.
3. 페이지를 새로고침한다.

기대값:

- 텍스트 X가 `0%`로 표시된다.
- 텍스트 Y가 `100%`로 표시된다.

---

## T05-05 — 글자색 복구

입력:

1. 글자색을 `#ff0000`으로 변경한다.
2. 페이지를 새로고침한다.

기대값:

- 글자색 입력값이 `#ff0000`이다.
- 미리보기의 문구가 같은 색으로 표시된다.

---

## T05-06 — 정렬과 굵기 복구

입력:

1. 정렬을 `오른쪽`으로 변경한다.
2. 글자 굵기를 `900`으로 변경한다.
3. 페이지를 새로고침한다.

기대값:

- 정렬 선택값이 `right`이다.
- 굵기 선택값이 `900`이다.

---

## T05-07 — 화면비 복구

입력:

1. 화면비 `9:16`을 선택한다.
2. 페이지를 새로고침한다.

기대값:

- `9:16` 버튼이 선택 상태다.
- 출력 크기가 `1080 × 1920`이다.

---

## T05-08 — 배경색 복구

입력:

1. 배경색을 `#123456`으로 변경한다.
2. 페이지를 새로고침한다.

기대값:

- 배경색 입력값이 `#123456`이다.
- 미리보기 배경에 같은 색이 표시된다.

---

## T05-09 — 빈 문구 복구

입력:

1. 문구 입력란의 내용을 모두 삭제한다.
2. 빈 문자열 상태에서 페이지를 새로고침한다.

기대값:

- 문구 입력란이 빈 상태로 유지된다.
- 기본 문구가 임의로 다시 나타나지 않는다.

---

## T05-10 — 새 작업 후 초안 제거

입력:

1. 문구를 `삭제되어야 할 초안`으로 변경한다.
2. 화면비를 `4:5`로 변경한다.
3. `새 작업`을 실행한다.
4. 페이지를 새로고침한다.

기대값:

- `삭제되어야 할 초안`이 다시 나타나지 않는다.
- 문구는 `여기에 문구를 입력하세요`이다.
- 화면비는 `1:1`이다.
- 배경색은 `#101827`이다.
- 글자 크기는 `72px`이다.
- 문구 폭은 `80%`이다.
- 텍스트 X는 `50%`이다.
- 텍스트 Y는 `70%`이다.
- 글자색은 `#ffffff`이다.
- 정렬은 `center`이다.
- 굵기는 `700`이다.

# 공통 사용 상한

AI A와 AI B에 동일하게 적용한다.

시간 상한:

45분

사용자 작업 요청 수 상한:

8회

요청 수 계산:

사용자가 해당 AI에게 보내는 작업 요청 메시지 1개를
1회로 계산한다.

---

# 검사 결과 기록 규칙

각 검사는 다음 중 하나로 기록한다.

PASS
FAIL

실제로 실행하지 않은 검사는 PASS로 기록하지 않는다.

오류 회차는 검사 10개를 한 번 실행한 회차 중
하나 이상의 FAIL이 나온 회차 수로 계산한다.

- 검사 입력 변경 금지
- 기대값 완화 금지
- 기대값 변경 금지
