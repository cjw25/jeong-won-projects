# T05 AI 공통 최초 요청

과제 3 「짤·카드 스튜디오」 프로젝트에 작은 개선 기능 하나를 구현해 주세요.

## 개선 기능

현재 편집 초안 자동저장 및 복구 기능을 추가합니다.

사용자가 문구, 글자 크기, 문구 폭, 텍스트 위치,
글자색, 정렬, 굵기, 화면비, 배경색 등을 변경하면
현재 편집 초안을 자동으로 저장합니다.

페이지를 새로고침하거나 다시 열었을 때
저장된 초안을 복원해야 합니다.

'새 작업'을 실행한 경우에는 이전 초안을 제거하고
기존 앱의 초기 상태로 돌아가야 합니다.

기존 사용자 템플릿 CRUD, JSON 가져오기/내보내기,
이미지 편집, PNG 다운로드 기능을 깨뜨리지 마세요.

## 검사

continuity/TEST-PLAN.md에 작업 시작 전에 고정된
T05-T01부터 T05-T10까지 정확히 같은 검사를 사용합니다.

검사 삭제, 완화, 기대값 변경은 허용하지 않습니다.

## 사용 상한

- 최대 작업 시간: 45분
- 최대 사용자 작업 요청: 8회
