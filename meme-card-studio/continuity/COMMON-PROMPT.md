# T05 공통 최초 요청

과제 3 「짤·카드 스튜디오」에 다음 개선 기능을 구현해 주세요.

## 개선 기능

현재 편집 초안 자동저장 및 복구 기능

사용자가 문구, 글자 크기, 문구 폭, 텍스트 위치,
글자색, 정렬, 굵기, 화면비, 배경색 등을 변경하면
현재 편집 상태를 자동 저장해야 합니다.

페이지를 새로고침하거나 다시 열었을 때
마지막 편집 상태를 복구해야 합니다.

'새 작업'을 실행한 경우에는 이전 자동저장 초안을 제거하고
기존 앱의 초기 상태로 돌아가야 합니다.

기존 템플릿 CRUD, JSON 가져오기/내보내기,
이미지 편집, PNG 다운로드 기능을 깨뜨리지 마세요.

## 고정 검사

continuity/TEST-PLAN.md에 미리 고정된
T05-01부터 T05-10까지 정확히 같은 검사를 사용합니다.

검사 삭제, 입력 변경, 기대값 완화,
기대값 변경은 허용하지 않습니다.

## 공통 사용 상한

- 작업 시간 최대 45분
- 사용자 작업 요청 최대 8회

## 작업 원칙

현재 저장소 상태를 먼저 확인하세요.

기능을 구현한 뒤
T05-01부터 T05-10까지 동일한 검사를 실행하세요.

검사 결과는 실제 결과 그대로 PASS 또는 FAIL로 기록하세요.

통과하지 못한 검사가 있어도
검사 기준을 수정하지 마세요.
