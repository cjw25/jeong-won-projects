SBOM Visibility Checker

SBOM을 통한 전이 의존성 가시성 확대가 취약 구성요소 식별 범위에 미치는 영향

이 앱은 직접 의존성만 확인하는 개발자와 보안 담당자가 전이 의존성까지 함께 살펴, 직접 분석에서 놓칠 수 있는 취약 구성요소를 확인하도록 돕습니다.

이 앱이 사용하는 논문의 방법

직접 분석은 직접 의존성 중 취약한 구성요소만 확인하고, SBOM 분석은 직접 의존성과 전이 의존성 전체 중 취약한 구성요소를 확인합니다.

이 앱은 실제 취약점을 자동 진단하는 보안 스캐너가 아니라, 논문에서 비교한 식별 범위를 사용자가 직접 확인해 볼 수 있는 비교 도구입니다.

HOW TO USE

세 가지만 하면 됩니다

1

구성요소 입력

이름, 의존성 유형, 취약 여부를 입력합니다.

2

분석 실행

직접 분석과 SBOM 분석을 동시에 계산합니다.

3

추가 발견 확인

직접 분석에서는 보이지 않았던 취약 구성요소를 확인합니다.

논문의 결과를 앱으로 바꾼 부분

논문에서는 전이 의존성까지 볼 때 취약 구성요소 식별 범위가 넓어질 수 있음 을 실험으로 확인했습니다.

이 앱에서는 사용자가 같은 프로젝트를 직접 의존성 기준과 SBOM 기준으로 비교해 그 차이를 직접 확인할 수 있도록 만들었습니다.
