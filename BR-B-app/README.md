# BR-B · SBOM Visibility Checker

## 프로젝트 설명

T10 논문

**「SBOM을 통한 전이 의존성 가시성 확대가 취약 구성요소 식별 범위에 미치는 영향」**

의 결과와 분석 방법을 실제로 사용해 볼 수 있도록 만든 애플리케이션이다.

## 앱 한 문장

직접 의존성만 확인하는 개발자·보안 담당자가 프로젝트 구성요소를 점검할 때,
이 앱이 SBOM 관점으로 전이 의존성까지 함께 비교해
직접 분석에서 놓칠 수 있는 취약 구성요소를 보여준다.

## 논문에서 반영한 결과

T10 실험 결과:

- 직접 의존성 수 합계: 21개
- SBOM 구성요소 수 합계: 72개
- 직접 분석 취약 구성요소 식별: 17건
- SBOM 분석 취약 구성요소 식별: 38건
- 추가 식별: 21건
- 추가 발견이 있었던 프로젝트: 7/10

논문에서 확인한 핵심은
직접 의존성만 확인하는 것보다
SBOM으로 전이 의존성까지 확인했을 때
식별 가능한 취약 구성요소의 범위가 확대될 수 있다는 것이다.

이 앱은 이 비교 방법을 그대로 사용한다.

## 사용자가 할 일 세 가지

1. 구성요소의 이름·의존성 유형·취약 여부를 입력한다.
2. `분석하기`를 눌러 직접 분석과 SBOM 분석을 비교한다.
3. 직접 분석에서는 놓치지만 SBOM 분석에서 추가로 확인되는 구성요소를 확인한다.

## 주의

이 앱은 실제 취약점을 자동 탐지하는 보안 스캐너가 아니다.

사용자가 입력한 취약 여부를 기준으로
직접 의존성 분석과 SBOM 관점의 가시성 차이를 보여 주는
논문 결과 반영용 비교 애플리케이션이다.
