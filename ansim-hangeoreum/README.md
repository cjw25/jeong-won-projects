# 안심 한 걸음 — 자동 보안 점검 도우미

## 자동화 중심 MVP

- **페이지 시작 시 자동 점검:** HTTPS/HTTP 연결 방식, 브라우저 저장 공간 시험, 브라우저가 보고하는 외부 리소스 호스트를 확인합니다. ‘지금 다시 확인’으로 수동 재실행도 가능합니다.
- **URL 입력 감지 자동 분석:** 사용자가 공유 가능한 URL을 입력하거나 붙여넣고 약 0.65초 멈추면, 버튼 없이 브라우저 내부에서 규칙 기반 분석을 수행합니다. ‘지금 분석’은 즉시 실행하는 보조 버튼입니다. 입력 중 조합 문자는 분석하지 않으며, 지우면 결과를 초기화합니다.
- **결과 자동 분류:** HTTP, URL 사용자 정보, IP 주소, punycode, 알려진 단축 도메인, 비기본 포트 등의 신호를 집계하고 해당 안내를 출력합니다. 안전 여부를 확정하거나 URL의 실제 목적지를 조회하지 않습니다.
- **진행률 자동 계산:** 사용자가 직접 확인한 4가지 기본 보안 항목의 완료 수와 진행률을 자동 갱신하고 완료 표시만 브라우저에 저장합니다.
- **사고 대응 안내:** 사용자가 선택한 상황에 맞는 일반적인 다음 행동을 안내합니다.

## 실행 및 확인

이 디렉터리의 `index.html`을 브라우저에서 엽니다. 연결 방식은 실행 환경(file/localhost/HTTPS)에 따라 달라집니다.

1. 페이지가 열리면 연결 방식, 저장 공간, 외부 리소스 상태가 자동 표시되는지 확인합니다.
2. ‘링크 분석’에서 `https://example.com`을 입력하고 입력을 멈춥니다. 추가 신호가 없는 형식 분석 결과가 버튼 없이 표시됩니다.
3. 입력을 `https://bit.ly/example` 또는 `http://192.0.2.1`로 바꾸면 각각 단축 도메인 신호 또는 HTTP/IP 신호가 자동 표시되는지 확인합니다. ‘입력과 결과 지우기’로 초기화합니다.

## 개인정보와 한계

전체 메시지, 비밀번호, 인증번호, 금융 정보는 입력하지 마세요. 비밀번호 재설정·결제·초대 URL처럼 개인용 토큰이 들어 있을 수 있는 링크도 분석기에 붙여넣지 마세요. 링크 분석은 입력값을 서버로 보내거나 저장하지 않으며, 실제 링크를 열지 않습니다. 기본 점검 완료 표시만 현재 브라우저의 로컬 저장소에 저장됩니다.

이 웹앱은 기기 설정, 설치 앱, SMS, 악성 파일이나 계정 상태를 자동 검사·차단하지 않습니다. 링크 분석 규칙은 위험 신호를 놓치거나 정상 링크에 표시할 수 있으며, 위험 신호가 없다고 안전하다는 뜻도 아닙니다. 실제 기기 보호 자동화에는 플랫폼별 공식 API와 권한, 개인정보·보안 검토가 필요합니다. 상세 범위는 [plan.md](plan.md)를 참고하세요.
