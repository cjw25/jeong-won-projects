## 개인정보와 한계

전체 메시지, 비밀번호, 인증번호, 금융 정보는 입력하지 마세요. 비밀번호 재설정·결제·초대 URL처럼 개인용 토큰이 들어 있을 수 있는 링크도 분석기에 붙여넣지 마세요. 링크 분석은 입력값을 서버로 보내거나 저장하지 않으며, 실제 링크를 열지 않습니다. 기본 점검 완료 표시만 현재 브라우저의 로컬 저장소에 저장됩니다.

이 웹앱은 기기 설정, 설치 앱, SMS, 악성 파일이나 계정 상태를 자동 검사·차단하지 않습니다. 링크 분석 규칙은 위험 신호를 놓치거나 정상 링크에 표시할 수 있으며, 위험 신호가 없다고 안전하다는 뜻도 아닙니다. 실제 기기 보호 자동화에는 플랫폼별 공식 API와 권한, 개인정보·보안 검토가 필요합니다. 상세 범위는 [plan.md](plan.md)를 참고하세요.
